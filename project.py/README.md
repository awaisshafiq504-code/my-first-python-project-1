# Velocity vs Time

## About

This is a simple computational physics project using python.

It calculates velocity using the equation:

v = u + at

where:
-u = initial velocity
-a = acceleration 
-t = time 

## Tools Used
-Python
-Matplotlib
-VS Code
-Git
-GitHub

## Result 
The program calculates velocity for different times and plots a velocity-versus-time graph.
